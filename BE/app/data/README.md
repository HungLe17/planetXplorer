# SPHEREx nominal spectra

Both files were extracted from the DR1/QR3 reference calibration published by Caltech/IPAC IRSA. The source FITS SHA-256 is `1da3549d363b6c7eb8ac0b709dbed6dafe2fd24eefe03ebee6e2e8912634694e`. [SPHEREx spectral channels, version 2, day 229 of 2026](https://irsa.ipac.caltech.edu/ibe/data/spherex/dr1/spectral_channels/cal-sch-v2-2026-229/spectral_channels_spx_cal-sch-v2-2026-229.fits)

- `spherex-spectra.json` preserves the 102 nominal rows of the `SPECTRAL_CHANNELS` extension, indexed by `DETECTOR` and `SUBCHAN`. The numerical columns are `WAVELENGTH`, `WL_MIN` and `WL_MAX` in micrometers. They give the median and range of the calibrated pixel-center wavelengths in a geometric channel. Adjacent ranges can overlap. [Explanatory Supplement §4.3.2, Tables 29–34](https://irsa.ipac.caltech.edu/data/SPHEREx/docs/SPHEREx_Expsupp.pdf#page=63)
- `channel-map-v2.u8.gz` contains the lossless gzip of the 2,040 × 2,040 `uint8` image in the `CHANNEL_MAP` extension, in FITS row order. The uncompressed SHA-256 is `29d44814de3894e1e93ee633a5e4f5fe2dff6264553196ae8eebb79cb0214c93`. Its `DETCOORD=sky` and `DETECTOR=ALL` header values specify one map in Level 2 image orientation for all six detectors. Its values 1–17 are nominal channels. Values 0 and 18 identify measured edge pixels outside the nominal set. [IRSA product description](https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-products/#additional-product-spectral-channels)

The backend samples the nearest native Level 2 detector pixel at the queried field center. For an IRSA cutout, the original zero-based pixel is the local zero-based pixel plus one minus `CRPIXiA` along each axis. This mapping precedes the viewer’s rotation, resampling and vertical flip. [IRSA cutout pixel coordinates](https://caltech-ipac.github.io/spherex-archive-documentation/spherex-data-products/#cutouts-of-spectral-image-mefs)
